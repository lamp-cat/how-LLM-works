# How LLMs Work 本地复刻

高保真复刻参考站：https://mlx.void.app/zh/chapters/overview

## 打开网站

双击 `启动网站.command`，或在本目录运行：

```bash
npm start
```

访问 http://localhost:5173/zh/chapters/overview 。首次访问会进入登录页，先创建账号，再使用邮箱和密码登录。无需安装 npm 依赖，需要 Node.js 22.13 或更新版本（使用内置 SQLite）。保持启动网站的终端开启。

## 已包含

- 原站的中文和英文页面、16 章课程，以及前端包中已有的拓展章节。
- 深色主题、公式排版、术语表、练习、测验与章节导航。
- softmax、BPE、RoPE、注意力等教学演示。
- 自由对话、模型加载与 J-Space 逐层透视的原站实现。
- MLX WebGPU Worker、WASM 内核、代码高亮资源和公式字体。
- 模型配置及真实 Qwen3.5 分词器。
- 本地 HTTP 服务，包含 Worker 路由、跨源隔离和模型文件 Range 请求。
- 邮箱注册、密码登录、账户页及退出登录，中英文界面与全局语言同步。

## 账户与鉴权

- `/auth/register`：昵称、邮箱、密码及确认密码。密码须为 8–128 个字符，邮箱不可重复。
- `/auth/login`：仅已注册账号可登录。注册成功不自动登录，需使用新账号登录。
- `/account`：查看昵称、邮箱、注册时间，继续学习或退出登录。课程菜单中的“我的账户”进入此页。
- 未登录访问课程会跳转登录页；登录后返回此前准备访问的课程。模型、WASM、Worker 和课程脚本接口同样要求登录。
- 密码通过随机盐与 scrypt 哈希保存，不保存明文密码。会话 token 随机生成，数据库仅保存其 SHA-256 摘要，Cookie 使用 HttpOnly 与 SameSite=Lax。会话有效期 7 天，退出后服务端立即撤销会话。
- 注册与登录有请求频率限制，写入接口验证同源 Origin 和 CSRF token。

账号与会话保存在 `~/.local/share/how-llms-work/auth.sqlite`，服务重启后保留。数据库位于网站静态目录之外，不通过网页公开。可设置 `AUTH_DATA_DIR` 改变数据库目录。多人实际使用时，每人自行注册，无预置账号。当前注册不发送验证邮件，不包含邮件找回密码功能。

当前服务仍默认仅监听本机。若后续部署至 HTTPS 站点，设置 `PUBLIC_ORIGIN=https://你的域名`，用于请求来源校验和 Secure Cookie；不要在普通 HTTP 下配置 HTTPS 来源。

## 真实模型

使用参考站的 `qwen3.5-0.8b-mlx-bf16` 模型。权重文件约 1.59 GiB，精确文件大小为 1,706,030,600 字节。GitHub 仓库不包含该权重文件，克隆后可运行 `npm run download:model` 下载；模型配置和分词器已包含在仓库中。模型包含 24 层、1024 维隐藏状态、248,320 个词表条目，线性注意力与全量注意力交错。

在网页点击“加载模型”，等待加载完成，再进入“自由对话”。这是真实模型运行入口；课程里标注为示意的动画仍是教学演示。

服务优先读取 `model/` 中的文件。缺少文件时，仅从参考站下载模型资源；不会把提示词发送到推理服务，计算发生在浏览器中。独立下载权重可运行：

```bash
npm run download:model
```

下载脚本支持分块续传，临时分块放在系统临时目录，下载完成后检查 safetensors 元数据与张量边界。可以通过环境变量 `MODEL_DIR` 指定另一个本地模型目录。

建议使用支持 WebGPU 的新版桌面 Chrome 或 Edge，并预留足够内存。网站必须通过本地服务打开，不能直接双击 `index.html`：推理内核需要 SharedArrayBuffer、Worker 和跨源隔离响应头。

## 实现来源与修改范围

这是参考站在 2026-10-25 公开发布的前端构建产物的本地运行版本。课程和推理逻辑复用了发布包，未取得或重建其原始 React/TypeScript 工程，不应理解为拥有原站源代码或发布许可。主包替换了吉祥物资源地址，并为右侧“动手试试”面板接入全局语言上下文；面板译文集中在 `assets/panel-i18n.js`。本地服务器、启动脚本和模型下载脚本是为本项目编写的。

课程文字、页面布局和已有交互保持原站设计。发布包虽然可以修改，但压缩代码不适合长期维护。若需要持续新增课程、改变模型后端或进行产品级二次开发，建议后续用独立源码重新实现，或取得原工程及适用授权。

公式字体和前端运行资源已保存在本地。页面排版使用的 Google Fonts、吉祥物生成图片仍可能需要网络；本地权重齐备后，模型计算不依赖云端推理。

## 文件

- `server.mjs`：本地服务，默认仅监听本机 5173 端口。
- `auth.mjs`：SQLite 账号存储、密码校验、会话和 CSRF 验证。
- `auth-ui/`：注册、登录、账户页面与课程中的账户入口。
- `index.html`、`assets/`：原站发布的课程运行资源。
- `mlx-core.opt.wasm`：真实推理内核。
- `model/`：模型配置、分词器和本地模型权重。
- `download-model.py`：可续传的模型下载工具。
- `asset-manifest.json`：资源来源和哈希记录。

端口冲突时可运行 `PORT=5174 npm start`，再访问对应端口。
